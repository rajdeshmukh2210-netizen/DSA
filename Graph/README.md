# Graph Representation Using Adjacency Matrix and DFS

## Description
This C++ program represents an undirected graph using an adjacency matrix. It allows users to create a graph, display its adjacency matrix, and perform Depth-First Search (DFS) traversal starting from a selected vertex.

## Features
- Create a graph by entering vertices and edges.
- Represent graph connections using an adjacency matrix.
- Display the adjacency matrix.
- Perform DFS traversal using recursion.
- Track visited vertices to avoid revisiting them.
- Menu-driven interface.

## Concepts Used
- Graph Data Structure
- Adjacency Matrix
- Depth-First Search (DFS)
- Recursion
- Visited Array
- C++ Classes and Arrays

## How to Run
Compile the program:

```bash
g++ graph.cpp -o graph
```

Run the program:

```bash
./graph
```

On Windows:

```bash
graph.exe
```

## Applications
- Graph traversal
- Exploring connected vertices
- Understanding recursive algorithms
- Learning graph representation techniques
