## 📌 What is DSA?

**Data Structures and Algorithms (DSA)** form the backbone of efficient software development. 
* **Data Structures** determine how data is organized, stored, and managed in memory.
* **Algorithms** provide step-by-step procedures to solve specific computational problems efficiently.

---

## 💡 Topics Covered So Far

### 1. Stack
A linear data structure operating on the **LIFO** (Last In, First Out) principle.
* **Key Features:** Elements are inserted and removed strictly from one end called the *Top*.
* **Core Operations:** 
  * `push()` – Add element to the top
  * `pop()` – Remove and return the top element
  * `peek()` / `top()` – View the top element

### 2. Queue
A linear data structure operating on the **FIFO** (First In, First Out) principle.
* **Key Features:** Insertion happens at the *Rear*, while deletion occurs at the *Front*.
* **Core Operations:**
  * `enqueue()` – Add element to the rear
  * `dequeue()` – Remove element from the front
  * `peek()` / `front()` – View the front element

  ### 3. Linked List
A linear, dynamic data structure where elements (nodes) store data alongside a reference/pointer to the next node.
* **Key Features:** Dynamic memory allocation; fast insertion and deletion compared to arrays.
* **Core Operations:** Insertion (Head/Tail/Middle), Deletion, Traversal, and Searching.
