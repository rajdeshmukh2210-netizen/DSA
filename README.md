# Data Structures and Algorithms (DSA) – C++ Programs

This repository contains my **Data Structures and Algorithms (DSA)** practical programs written in **C++** for academic submission.

## Programs Included

### 1. Stack Implementation (`stack.cpp`)

* Implements the **Stack** data structure using an array.
* Supports basic operations:

  * Push
  * Pop
  * Display
* Demonstrates the **LIFO (Last In, First Out)** principle.

### 2. Queue Implementation (`q.cpp`)

* Implements the **Queue** data structure using an array.
* Supports basic operations:

  * Enqueue
  * Dequeue
  * Peek
  * Display
* Demonstrates the **FIFO (First In, First Out)** principle.

### 3. Library Stack System (`LL.cpp`)

* A simple library-based example using a **Stack**.
* Simulates book management with operations such as:

  * Return Book (Push)
  * Arrange Book (Pop)
  * View Top Book (Peek)
  * Display All Books
* Shows how stack operations can be applied in a real-world scenario.

## Technologies Used

* **Language:** C++
* **Concepts:** Stack, Queue, Arrays, Classes, Object-Oriented Programming (OOP)

## Purpose

This repository is created for **DSA practical submission** and to practice the implementation of fundamental data structures using C++.
