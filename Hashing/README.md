# Hashing in C++ Using Linear Probing

## Description
This C++ program implements a hash table to store integer keys. It uses the modulo operation as the hash function and linear probing to handle collisions. Users can choose between insertion with replacement and insertion without replacement.

## Features
- Create a hash table of a specified size.
- Calculate hash indices using the modulo operator.
- Insert keys without replacement.
- Insert keys with replacement.
- Handle collisions using linear probing.
- Display the contents of the hash table.
- Menu-driven interface.

## Concepts Used
- Hashing
- Hash Functions
- Hash Tables
- Collision Resolution
- Linear Probing
- Insertion with Replacement
- Insertion without Replacement
- C++ Classes and Arrays

## How to Run
Compile the program:

```bash
g++ Hashing.cpp -o Hashing
```

Run the program:

```bash
./Hashing
```

On Windows:

```bash
Hashing.exe
```
