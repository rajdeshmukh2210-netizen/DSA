# Graph Representation Using Adjacency Matrix and Kruskal's Algorithm

## Description
This C++ program represents a weighted, undirected graph using an adjacency matrix. It allows users to create a graph, display the matrix, and find a Minimum Spanning Tree (MST) using Kruskal's algorithm.

## Features
- Create a weighted graph by entering vertices and edges.
- Store graph connections and edge weights in an adjacency matrix.
- Display the adjacency matrix.
- Sort edges by weight.
- Find a Minimum Spanning Tree using Kruskal's algorithm.
- Display the selected edges and total MST weight.

## Concepts Used
- Graph Data Structure
- Adjacency Matrix
- Weighted Graphs
- Kruskal's Algorithm
- Minimum Spanning Tree (MST)
- Edge Sorting
- C++ Classes and Structures

## How to Run
Compile the program:

```bash
g++ graph_adj_mat.cpp -o graph_adj_mat
```

Run the program:

```bash
./graph_adj_mat
```

On Windows:

```bash
graph_adj_mat.exe
```
