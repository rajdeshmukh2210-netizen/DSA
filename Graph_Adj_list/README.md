# Graph Representation Using Adjacency List and BFS

## Description
This C++ program represents an undirected graph using an adjacency list. It allows users to create a graph, display its adjacency list, and perform Breadth-First Search (BFS) traversal from a selected starting vertex.

## Features
- Create a graph by entering vertices and edges.
- Represent graph connections using an adjacency list.
- Display the adjacency list.
- Perform BFS traversal using a queue.
- Menu-driven interface for easy interaction.

## Concepts Used
- Graph Data Structure
- Adjacency List
- Breadth-First Search (BFS)
- Queue
- C++ Classes and Vectors

## How to Run
Compile the program:

```bash
g++ graph_adj_list.cpp -o graph_adj_list
```

Run the program:

```bash
./graph_adj_list
```

On Windows:

```bash
graph_adj_list.exe
```

## Applications
- Graph traversal
- Finding reachable vertices
- Understanding graph representation and BFS
